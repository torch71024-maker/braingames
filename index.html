SCAN
Visual Search · Peripheral Attention
A grid of similar symbols — one is different. Find it before time runs out. Grids get larger and differences grow subtler. Trains the visual system to cover the whole field.

SIMON
Working Memory · Sequential Processing
Buttons light up in sequence. Reproduce it exactly. Sequences grow longer, colors multiply, pace quickens. Trains the mental workspace used in everything.

TRACK
Visual Tracking · Sustained Attention
Dots light up then blend into a moving swarm. Track your target through the chaos — tap it when they freeze. Harder levels add more targets and more dots.

GRID
Spatial Memory · Route Recall
A path snakes through a grid — bottom to top. Memorise it. When the timer runs out or you hit STOP, the path vanishes. Tap it back in order. One wrong step turns everything red.

POPULE
Subitizing · Selective Attention
Items flash briefly — how many were there? As levels rise: count only the orange ones, or only the orange circles. Fast filtering under time pressure.
